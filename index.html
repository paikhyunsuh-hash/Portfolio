  • 2025. 00. 00.

    TMDb(The Movie Database) API를 활용하여 최신 영화 정보, 인기 차트, 추천 영화, 상영 예정작 등을 실시간으로 제공하는 영화 정보 웹사이트입니다.

    사용자는 원하는 영화 제목을 검색할 수 있으며, 영화의 포스터, 출시 연도, 장르, 평점, 줄거리 등을 직관적으로 확인할 수 있습니다.

    다크모드/라이트모드 전환, “더보기” 페이지네이션, 마우스 호버 상세 설명 등 다양한 UI/UX 기능을 포함하고 있습니다.

  • 2025. 00. 00.

    TO-DO LIST 웹 애플리케이션은 사용자가 할 일을 작성하고 관리할 수 있는 간단한 메모형 태스크 관리 서비스입니다.

    입력 → 추가 → 완료/미완료 변경 → 삭제 → 메모 색상 변경까지 지원하며, UI·UX와 코드 구조의 직관성을 고려해 설계했습니다.

    순수 HTML, CSS, JavaScript만으로 구현되어 있으며, DOM 조작, 이벤트 처리, 배열 데이터 관리 등 Web Front-End의 기본기를 탄탄하게 담고 있는 프로젝트입니다.

  • 숫자게임

    2025. 00. 00.

    숫자게임은 사용자가 1~100 사이의 숫자를 입력해 컴퓨터가 랜덤으로 생성한 숫자를 맞추는 게임입니다.

    플레이어에게는 총 5번의 기회가 주어지며, 매 입력마다 결과가 시각적으로 표현됩니다.

    심플한 구조지만, 유효성 검사 → 중복 입력 방지 → 랜덤 숫자 생성 → 상태 변화 렌더링 → 게임 종료 처리까지 게임 로직의 핵심 흐름을 모두 담은 프로젝트입니다.

    배경 영상과 애니메이션을 활용하여 아케이드 느낌의 UI를 구현해 누구나 직관적으로 즐길 수 있게 제작했습니다.

  • 날씨

    2025. 00. 00.

    이 프로젝트는 OpenWeatherMap API를 활용하여 전 세계 도시의 실시간 날씨 정보를 제공하는 웹 애플리케이션입니다.

    API 통합 및 검색: OpenWeatherMap API를 통해 날씨 데이터를 실시간으로 가져오며, 사용자 위치 기반 정보 표시 및 도시 이름 검색 기능을 구현했습니다.

    다이내믹 UI/UX: 날씨 상태(맑음, 흐림, 비, 눈)에 따라 배경 영상을 동적으로 전환하고, 현지 시간을 정확히 계산하여 표시했습니다.

    데이터 시각화: Chart.js 라이브러리를 사용하여 3시간 간격의 온도 변화 추이를 꺾은선 그래프로 시각화하여 사용자가 정보를 직관적으로 파악할 수 있도록 했습니다.
