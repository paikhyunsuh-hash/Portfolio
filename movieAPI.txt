⭐ 주요 기능 (Key Features)
🔍 1. 영화 검색 기능

제목 기반 검색

엔터 키 입력 또는 검색 버튼 클릭으로 실행

검색 결과 페이징 지원

🎬 2. 영화 카테고리별 조회

현재 상영작 (Now Playing)

인기 영화 (Popular)

추천 영화 (Top Rated)

상영 예정작 (Upcoming)

클릭 시 해당 카테고리의 1페이지부터 자동 로드

🎞 3. 영화 카드 정보 표시

각 영화 카드에는 아래 정보가 포함됨:

포스터 이미지

영화 제목

출시 연도

장르(Genre API 변환)

평균 평점

줄거리(hover시 표시되는 설명 박스)

🖱 4. 호버(Hover) 상세 보기

포스터 위에 마우스를 올리면 시놉시스/평점/장르 노출

포스터는 blur 처리되어 시각적으로 집중 가능

🌗 5. 화면 모드 전환 (다크 모드/라이트 모드)

아이콘 클릭 시 즉시 테마 변경

전체 영역(body, header, 카드 등)에 스타일 동기화 적용

➕ 6. 더보기(Pagination) 기능

“더보기” 버튼 클릭 시 다음 페이지 영화 목록이 이어서 아래에 append

기존 데이터 유지 → 자연스러운 무한 스크롤 느낌

⬆ 7. 위로가기 버튼

페이지 하단에서 “위로” 버튼 클릭 시 부드러운 스크롤로 최상단 이동(jQuery animation)

🏷 8. 장르 자동 변환 기능

TMDb 장르 API 요청 → 장르 id → 장르 이름으로 자동 변환

“액션, 드라마, 코미디…” 등 정확한 장르 제공

🌐 9. 영화 상세 페이지 연결

카드 클릭 시 TMDb 공식 상세 페이지로 이동

SEO-friendly URL 구조 자동 생성
