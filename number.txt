주요 기능 (Key Features)
1️⃣ 랜덤 숫자 생성 (Random Number Generator)

페이지 로드 또는 게임 재시작 시
1~100 사이의 랜덤 숫자 자동 생성

Math.random()을 활용한 난수 알고리즘 사용

computerNum = Math.floor(Math.random() * 100 + 1);

2️⃣ 숫자 입력 및 비교 기능

사용자가 숫자를 입력하면 아래 규칙에 따라 결과 출력:

조건	화면 결과	이미지 변경
입력 숫자 < 1 또는 > 100	“1부터 100까지 입력해주세요”	(변경 없음)
입력 숫자가 이전에 입력한 숫자와 동일	“이미 입력한 숫자입니다”	유지
입력 < 정답	WRONG!	down.png
입력 > 정답	WRONG!	up.png
입력 = 정답	bingo	bingo.png
3️⃣ 중복 입력 방지 기능

입력한 숫자를 history 배열에 저장

동일 숫자 재입력 시 경고를 띄우고 기회(chance)를 소모하지 않음

if (history.includes(userNum)) {
  result.textContent = "이미 입력한 숫자입니다.";
  return;
}

4️⃣ 5번의 기회(Chances) 시스템

게임 시작 시 chance = 5

숫자를 입력할 때마다 차감

실시간 화면 표시:

남은찬스 : 4번
남은찬스 : 3번 …


기회가 0이 되면:

게임 종료

PLAY 버튼 비활성화

“gameover” 표시

over.png로 이미지 변경

5️⃣ 직관적인 시각 피드백 (UP / DOWN / BINGO 이미지)

숫자 비교만 텍스트로 알려주는 게 아니라
UP, DOWN, BINGO 이미지로 정답 방향을 안내

플레이 감각을 높이는 시각적 요소

6️⃣ RESTART 기능

RESET 버튼을 누르면 게임 전체 상태 초기화:

입력창 초기화

chance = 5로 복구

랜덤 숫자 재생성

시작 이미지(play.png)로 변경

result 문구 초기화

history(입력 기록) 비움

7️⃣ 입력창 UX 개선

입력창 클릭(focus) 시 기존 입력값 자동 삭제
→ 플레이 흐름이 빠르고 부드럼

user.addEventListener("focus", () => {
  user.value = "";
});

8️⃣ 반응형 UI (Responsive Web)

모바일 사용자까지 고려하여 미디어쿼리로 화면 비율 최적화

작은 디바이스에서도 화면 깨짐 없이 자연스러운 배치

배경 동영상 + 카드 UI 조합으로 아케이드 게임 느낌 구현

🎨 UI·애니메이션 포인트
✔ 배경 동영상 사용

게임 몰입도를 높이기 위한 자동 재생 loop 영상

object-fit: cover 로 풀스크린 자연스럽게 처리

✔ SEGA & Galmuri Pixel 폰트 적용

게임 컨셉에 맞는 레트로 감성 연출

✔ “Try Again” 느낌의 result 텍스트 애니메이션

result 영역에 scale 효과 애니메이션 반복 적용
→ 사용자가 계속 집중하도록 유도
