⭐ 주요 기능 (Key Features)
1️⃣ 할 일 입력 및 추가 기능

입력창에 텍스트 입력 후
"+" 버튼 또는 Enter 키로 새로운 할 일을 생성

사용자가 입력한 텍스트는 객체 형태로 저장되며 taskList 배열로 관리

랜덤 ID(Date.now())로 고유한 태스크 구분

2️⃣ 할 일 완료 / 미완료 상태 변경

각 할 일 카드의 “completed / incomplete” 버튼 클릭 시
→ isComplete 값을 토글하여 상태 변경

완료된 항목은:

줄이 그어진 스타일(line-through)

배경 흐림 처리(opacity)

회색톤 컬러 적용

미완료 항목은 기존 스타일 유지

3️⃣ 할 일 삭제 기능

각 태스크 카드의 “X” 버튼 클릭 시 해당 ID를 가진 데이터를 배열에서 삭제

필터링 방식 사용:

taskList = taskList.filter(task => task.id !== id);

4️⃣ 메모 색상 변경 기능 (Color Tagging)

각 카드에는 4가지 색상 태그 버튼이 있음:

🔴 Red

🟡 Yellow

🔵 Blue

🟢 Green

클릭 시 해당 색상이 즉시 카드 배경에 적용
→ 사용자가 중요도·분류 기준에 따라 시각적으로 구분할 수 있음

5️⃣ 실시간 렌더링 (DOM Re-render)

모든 데이터 변경(add/delete/update/color-change) 후
항상 render()를 호출하여 UI를 즉시 갱신

모든 카드 HTML 구조를 동적으로 생성해 화면에 렌더링

데이터 중심의 구조이므로 상태 관리가 명확함

6️⃣ 반응형 UI (Responsive Web)

CSS Media Query 사용하여 디바이스별 맞춤 UI 지원

모바일 (300px~600px)

태블릿 (600px~1024px)

PC (1024px↑)

입력창, 보드 크기, 버튼 정렬 등을 화면 크기에 따라 유동적으로 변경

7️⃣ 직관적이고 감성적인 메모 디자인

손글씨 스타일 기반 폰트

스티커 메모장 느낌의 카드 스타일

박스 그림자, 음영, 부드러운 컬러로 시각적 안정감 제공

전체 배경은 따뜻한 톤의 편안한 느낌

🔧 기술적 특징 (Technical Highlights)
✔ 배열 기반 상태 관리

모든 태스크를 taskList 배열로 관리하여
추가/삭제/업데이트를 명확하게 수행.

✔ 객체 구조 사용
{
  id: number,
  taskContent: string,
  isComplete: boolean,
  color: string
}


확장성 높은 데이터 구조로 구성.

✔ DOM 동적 랜더링

HTML 요소를 템플릿 문자열로 동적 생성
→ 유지보수 편함

✔ 전역 이벤트 및 분리된 기능 함수

addTask()

deleteTask()

complete()

changeColor()

render()

각 기능이 함수로 분리되어 구조적이다.

✔ UX 강화 요소

입력창 focus 시 자동 초기화

Enter 입력 지원

카드별 색상 선택 지원

완료 시 시각적 구분 강화

📂 개발 목적 및 배운 점
💡 DOM 조작과 배열 기반 CRUD의 기본기를 다짐

이 프로젝트를 통해
프론트엔드 기본 개념인 DOM 조작, 이벤트 바인딩, 배열 CRUD 처리에 대한 경험을 쌓음.

💡 사용자 경험을 고려한 UI 설계

단순한 TO-DO 앱이지만
색상 태깅, 반응형, 시각적 강조 등 UX 요소를 세심하게 넣어 실제 서비스처럼 보이도록 구현.

💡 확장 가능 구조 설계

현재는 로컬 데이터 기반이지만,
향후 LocalStorage, API 연동, Drag & Drop, 카테고리 기능 추가도 쉽게 할 수 있도록 구조화됨.
